## 2. نظام تكليف المهام للمستخدمين

### 2.أ Database (migration جديدة)
- إضافة عمود `assigned_to uuid` و `assigned_by uuid` و `priority text` و `completed_at timestamptz` على جدول `tasks` (إذا غير موجودة).
- إضافة فهرس `idx_tasks_assigned_to`.
- View بسيط `v_tasks_user_stats` يعطي لكل مستخدم: عدد المهام، المكتملة، المتأخرة، نسبة الإنجاز.
- RLS: المستخدم يرى المهام المُكلّف بها أو المُكلِّف لها؛ الأدمن/CFO يرى الكل.

### 2.ب الواجهة — تحديث `src/routes/_authenticated/tasks/index.tsx`
- إضافة حقل **"المُكلَّف"** في نموذج إنشاء المهمة (Select من قائمة المستخدمين عبر `auth.users` view أو جدول `profiles`).
- إضافة حقل **"الأولوية"** (low / medium / high / urgent) مع badge ملوّن.
- إضافة **3 تبويبات** أعلى الصفحة:
  - **مهامي** (المُكلَّف بها للمستخدم الحالي)
  - **كلّفتها** (التي أنشأها)
  - **جميع المهام** (للأدمن/CFO فقط)
- زر ✓ بالفعل موجود — توسعته ليسجّل `completed_at = now()` ويُظهر toast.
- **Dashboard Header** أعلى الصفحة: 4 بطاقات KPI (إجمالي، قيد التنفيذ، مكتملة، متأخرة) + شريط تقدم لكل مستخدم (Progress).
- فلاتر: حسب المستخدم، الحالة، الأولوية، التاريخ.

### 2.ج صفحة جديدة `/tasks/team` (للأدمن)
- جدول يعرض لكل مستخدم: عدد المهام / المكتملة / المتأخرة / % الإنجاز + chart عمودي بسيط (Recharts).

## 3. نماذج الزكاة والضريبة الرسمية (هيئة الزكاة والضريبة والجمارك)

### 3.أ إعادة بناء `src/routes/_authenticated/tax-tools/index.tsx`
تبويبان رئيسيان مع توسعة كاملة مطابقة للنماذج المرفقة:

#### تبويب 1: **إقرار ضريبة القيمة المضافة** (مطابق لـ `نموذج_الإقرار_الضريبي.xlsx`)
رأس النموذج: اسم الشركة، الرقم الضريبي، طبيعة النشاط، الفترة الضريبية، العنوان.

**جدول المبيعات** (4 صفوف):
- ع-1: المبيعات الخاضعة للنسبة الأساسية 15%
- ع-2: المبيعات المحلية الخاضعة لنسبة صفر
- ع-3: الصادرات
- ع-4: المبيعات المعفاة
- **إجمالي المبيعات** (محسوب)

**جدول المشتريات** (5 صفوف):
- ش-1: المشتريات الخاضعة للنسبة الأساسية 15%
- ش-2: الاستيرادات المسددة للجمارك
- ش-3: الاستيرادات بآلية الاحتساب العكسي
- ش-4: المشتريات الخاضعة لنسبة الصفر
- ش-5: المشتريات المعفاة
- **إجمالي المشتريات** (محسوب)

3 سطور ختامية: الضريبة المستحقة الحالية، المرحّل من فترات سابقة، **صافي المستحق/المسترد**.

كل صف يحتوي على: المبلغ، التعديلات، قيمة الضريبة (محسوبة تلقائياً 15% حيث ينطبق).

#### تبويب 2: **الإقرار الزكوي/الضريبي الموحد** (نموذج 10)
أقسام مطابقة للـ PDF:
1. **بيانات المكلف** — الرقم المالي، الفرع، السنة المالية، الاسم التجاري، نسب الملكية (سعودي/غير سعودي رأس المال + الربح)، النشاط، العنوان.
2. **(أ) الدخل** — إيرادات العقود، نشاط التأمين، الإيرادات التشغيلية، إجمالي التشغيل، مكاسب/خسائر رأسمالية، إيرادات أخرى، إجمالي الإيرادات.
3. **(ب) التكاليف والمصاريف** — تكلفة البضاعة المباعة (مخزون أول، مشتريات خارجية/داخلية، مخزون آخر) + المصاريف (الباطن، استئجار آلات، صيانة، رواتب، مزايا، تأمينات، ...إلخ).
4. **التعديلات الزكوية/الضريبية** — مع صافي الربح المعدّل لكل من الزكاة والضريبة.
5. **الوعاء الزكوي** — الإضافات (رأس مال، أرباح مدورة، مخصصات، احتياطيات، ديون) − الحسميات → الوعاء النهائي → **الزكاة المستحقة 2.5%**.
6. **الوعاء الضريبي** — للمكوّن الأجنبي → ضريبة الدخل المستحقة.
7. **المركز المالي** — أصول متداولة/ثابتة، خصوم متداولة/طويلة، حقوق الملكية، (رصيد بداية / نهاية).
8. **شهادة المحاسب القانوني** — حقول الاسم، الترخيص، الرقم المالي، التوقيع.

كل قسم في Card قابل للطي (Accordion)، مع:
- حفظ القيم في `localStorage` (مفتاح لكل سنة مالية).
- زر **تصدير Excel** ينتج ملفاً بنفس بنية النموذج الرسمي.
- زر **طباعة PDF** بتنسيق رسمي (A4، عربي RTL، شعار هيئة الزكاة) جاهز للتقديم.
- زر **جلب تلقائي من النظام**: يقرأ الأرقام من جداول `journal_entries` / `financial_statements` إذا توفرت ويملأ الحقول.
